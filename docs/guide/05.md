# 05장 ∙ 내장 함수 - 문자열, 숫자, 날짜, 조건식

## 학습 목표

- 문자열·숫자·날짜 함수로 값을 가공할 수 있다.
- `CAST` / `::` 로 형변환하고 `to_char` 로 서식을 지정할 수 있다.
- `CASE`, `COALESCE`, `NULLIF` 로 조건에 따라 값을 바꿀 수 있다.

예제 파일: `examples/05_functions.sql`

## 문자열 함수

| 함수 | 설명 | 예 → 결과 |
|---|---|---|
| `length(s)` | 글자 수 (한글도 1글자) | `length('데이터')` → 3 |
| `upper` / `lower` | 대/소문자 | `upper('sql')` → SQL |
| `substring(s FROM n FOR m)` | 부분 문자열 | `substring('abcdef' FROM 2 FOR 3)` → bcd |
| `left(s, n)` / `right(s, n)` | 왼쪽/오른쪽 n글자 | `left('010-1234', 3)` → 010 |
| `\|\|`, `concat`, `concat_ws` | 연결 (concat 은 NULL 무시) | `concat_ws('-', 'a', 'b')` → a-b |
| `trim` / `ltrim` / `rtrim` | 공백(또는 지정 문자) 제거 | |
| `replace(s, a, b)` | a 를 b 로 모두 바꿈 | |
| `lpad` / `rpad` | 왼쪽/오른쪽 채우기 | `lpad('42', 5, '0')` → 00042 |
| `split_part(s, 구분자, n)` | 구분자로 나눈 n번째 | `split_part('a@b.com', '@', 2)` → b.com |
| `position(a IN s)` | 위치 (없으면 0) | |
| `regexp_replace` / `~` | 정규식 치환 / 정규식 일치 | 15장 트리거 예제 |

> [!POINT] 연결 연산자와 NULL
> `'a' || NULL` 은 NULL 이지만 `concat('a', NULL)` 은 `'a'` 입니다(4장 04-09 결과와 비교). 이름 + 별명처럼 NULL 이 섞일 수 있는 연결은 `concat` 이나 `COALESCE` 를 쓰세요.

> [!WARN] 정수 ÷ 정수 = 정수
> 평균, 비율, 퍼센트 계산에서 가장 흔한 실수입니다. `count(*) / 3` 이나 `a / b * 100` 은 소수점이 잘립니다. **`100.0 * a / b`** 처럼 앞에 실수를 곱하거나 `::numeric` 으로 바꿔 계산하세요. 6장 이후 비율 계산 예제가 모두 `100.0 *` 로 시작하는 이유입니다.

형변환은 표준 문법 `CAST(값 AS 타입)` 과 PostgreSQL 단축 문법 `값::타입` 이 있습니다.

## 날짜와 시간

| 함수 / 연산 | 설명 |
|---|---|
| `current_date`, `current_time`, `now()` | 오늘 날짜, 현재 시각, 현재 일시(트랜잭션 시작 시각) |
| `날짜 + 정수` / `날짜 - 날짜` | n일 후 / 두 날짜 사이 일수(정수) |
| `+ interval '1 month'` | 기간 더하기 (`'2 hours'`, `'1 year 3 days'` 등) |
| `age(a, b)` | a - b 를 년·월·일로 |
| `EXTRACT(필드 FROM 일시)` | YEAR, MONTH, DAY, HOUR, DOW(0=일), ISODOW(1=월), QUARTER, EPOCH 등 |
| `date_trunc('month', 일시)` | 해당 단위의 시작으로 자르기 (월별·주별 집계의 핵심) |
| `to_char(일시, '서식')` | 문자열로 (YYYY, MM, DD, HH24, MI, SS, Day, Q 등) |
| `to_date` / `to_timestamp` | 문자열을 날짜로 |

## 조건식 - CASE, COALESCE, NULLIF

```
CASE WHEN 조건1 THEN 결과1          CASE 식
     WHEN 조건2 THEN 결과2               WHEN 값1 THEN 결과1
     ELSE 기본값                         WHEN 값2 THEN 결과2
END                                      ELSE 기본값 END
```

CASE 는 위에서부터 차례로 검사해 **처음 참인 WHEN** 의 결과를 돌려줍니다. 그래서 범위 조건은 큰 값부터 씁니다(05-13).

## 정리

- 비율 계산은 `100.0 *`, 날짜 범위 집계는 `date_trunc`, 서식은 `to_char`.
- NULL 대체는 `COALESCE`, 0 나누기 방지는 `NULLIF(x, 0)`.
- CASE 는 위에서부터 첫 번째로 참인 조건을 쓴다.
