## GROUP BY

GROUP BY 는 같은 값끼리 행을 묶어 **그룹마다 한 행**으로 만듭니다. 그 결과 SELECT 에는 “그룹마다 하나로 정해지는 값”만 올 수 있습니다.

## HAVING - 그룹 거르기

| 구분 | WHERE | HAVING |
|---|---|---|
| 실행 시점 | 그룹을 만들기 **전** (행 단위) | 그룹을 만든 **후** (그룹 단위) |
| 집계 함수 | 사용 불가 | 사용 가능 |
| 예 | 취소 주문 제외 | 주문이 10건 이상인 고객만 |

> [!TIP] FILTER 는 피벗(교차표)의 기본기
> `count(*) FILTER (WHERE 조건)` 를 여러 개 나열하면 상태별·월별 교차표를 한 쿼리로 만들 수 있습니다. 표준 SQL 이며, 다른 DB 에서는 `sum(CASE WHEN 조건 THEN 1 ELSE 0 END)` 로 같은 결과를 냅니다(06-09 의 마지막 컬럼).

## [심화] 소계와 총계 - ROLLUP, GROUPING SETS

| 구문 | 만들어지는 그룹 |
|---|---|
| `GROUP BY ROLLUP (a, b)` | (a, b), (a), () → 상세 + a별 소계 + 총계 |
| `GROUP BY CUBE (a, b)` | (a, b), (a), (b), () → 가능한 모든 조합 |
| `GROUP BY GROUPING SETS ((a), (b), ())` | 지정한 그룹만 |

## 정리

- 집계 함수는 NULL 을 무시한다. count(*) 만 예외.
- GROUP BY 후 SELECT 에는 그룹 컬럼과 집계 함수만.
- 행 조건은 WHERE, 그룹 조건은 HAVING. 조건부 집계는 FILTER.
