## 이 교안의 구성

이 교안은 **SQL을 처음 배우는 수강생**을 대상으로, PostgreSQL 설치부터 실무 수준의 심화 주제(인덱스 튜닝, 트랜잭션과 동시성, PL/pgSQL, JSONB, 권한·보안, 운영, Python 연동)까지 다루는 강사용 교안입니다. 각 장은 같은 순서로 구성되어 있어 수업 준비와 진행이 쉽습니다.

| 구성 요소 | 내용 | 활용 방법 |
|---|---|---|
| 학습 목표 | 그 장이 끝났을 때 수강생이 할 수 있어야 하는 것 | 수업 시작 시 화면에 띄우고 읽어 주기 |
| 수업 흐름 | 시간 배분표 | 진도 조절 기준 (지연 시 [심화] 예제 생략) |
| 핵심 개념 | 개념 설명, 그림, 표 | 판서·설명 원고 |
| 예제 | 저장소의 예제 SQL과 **실제 실행 결과** | 라이브 코딩 시 그대로 따라 입력 |
| 강사 노트 | 설명 요령, 비유, 시간 관리 팁 | 강사 전용 (수강생 배포 X) |
| 주의 / 예상 질문 | 수강생이 자주 틀리는 부분, 자주 하는 질문과 답 | 실습 중 순회 지도 시 참고 |
| 실습 문제 | 장별 확인 문제 (정답은 부록 A) | 실습 시간 과제, 다음 날 복습 퀴즈 |

> [!NOTE] 실행 결과에 대하여
> 교안의 모든 ‘실행 결과’는 저장소의 예제 파일을 **PostgreSQL 18.6**에서 실제로 실행해 자동으로 넣은 것입니다(`tools/build_guide.py`). 수강생 PC에서도 같은 데이터(`setup/02_seed.sql`)를 쓰므로 결과가 같게 나옵니다. 단, 현재 시각(`now()`), 버전 문자열, 실행 계획의 비용·시간, 객체 크기, 내부 번호(xmin 등)는 환경마다 다릅니다.
> 한국어 Windows에 설치하면 psql 메시지가 한글로 나옵니다(예: `(5 rows)` → `(5개 행)`, `ERROR:` → `오류:`). 교안은 검색하기 쉬운 영어 메시지 기준입니다.
> 수업 도구인 **DBeaver 에서는 결과가 표(그리드)로** 나오고, `UPDATE 1` 같은 메시지는 Statistics 탭에 표시됩니다. 교안의 psql 형식 결과와 모양만 다르고 내용은 같습니다.

## 표기 규칙

- SQL 키워드는 대문자(`SELECT`), 테이블·컬럼 이름은 소문자(`customers`)로 씁니다. PostgreSQL은 대소문자를 구분하지 않지만 읽기 쉽게 하기 위한 관례입니다.
- 실습 도구는 **DBeaver** 입니다. `psql` 에서 `\` 로 시작하는 명령(`\dt`, `\d`)은 SQL이 아니라 psql 프로그램의 **메타 명령**이라 DBeaver 에서는 동작하지 않으므로, 예제는 모두 SQL 로 작성했습니다(18장 `\copy` 만 psql 전용).
- `[심화]` : 기초 과정에서는 생략 가능한 내용, `[error]` : 일부러 오류를 보여 주는 예제입니다.
- 금액 단위는 원, 직원 연봉(`salary`)은 만원 단위입니다.
