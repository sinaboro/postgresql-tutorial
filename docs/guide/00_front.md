## 이 교재의 구성

이 교재는 **SQL을 처음 배우는 분**을 위해 PostgreSQL 설치부터 실무 수준의 심화 주제(인덱스 튜닝, 트랜잭션과 동시성, PL/pgSQL, JSONB, 권한·보안, 운영, Python 연동)까지 차례로 다룹니다. 각 장은 같은 순서로 구성되어 있습니다.

| 구성 요소 | 내용 |
|---|---|
| 학습 목표 | 그 장을 마치면 할 수 있어야 하는 것 |
| 개념 설명 | 문법, 그림, 비교표 |
| 예제 | 저장소의 예제 SQL 과 **실제 실행 결과**. 직접 실행해 결과를 비교해 보세요 |
| 핵심 포인트 | 꼭 기억할 내용, 이해를 돕는 비유 |
| TIP / 주의 / 참고 | 알아 두면 좋은 기능, 자주 틀리는 부분, 보충 설명 |
| 자주 묻는 질문 | 수업에서 자주 나오는 질문과 답 |
| 실습 문제 | 장별 확인 문제 (문제지 `exercises/`, 정답 `solutions/`) |

> [!NOTE] 실행 결과에 대하여
> 교재의 모든 ‘실행 결과’는 저장소의 예제 파일을 **PostgreSQL 18**에서 실제로 실행해 넣은 것입니다. 여러분도 같은 Docker 환경과 같은 샘플 데이터를 쓰므로 같은 결과가 나옵니다. 단, 현재 시각(`now()`), 실행 계획의 비용·시간, 객체 크기, 내부 번호(xmin 등)는 실행할 때마다 다릅니다.
> 교재의 결과는 psql 형식(글자로 그린 표)입니다. **DBeaver 에서는 같은 내용이 결과 그리드(표)로** 나오고, `UPDATE 1` 같은 메시지는 Statistics 탭에 표시됩니다.

## 표기 규칙

- SQL 키워드는 대문자(`SELECT`), 테이블·컬럼 이름은 소문자(`customers`)로 씁니다. PostgreSQL 은 대소문자를 구분하지 않지만 읽기 쉽게 하기 위한 관례입니다.
- `psql` 에서 `\` 로 시작하는 명령(`\dt`, `\d`)은 SQL 이 아니라 psql 프로그램의 **메타 명령**이라 DBeaver 에서는 동작하지 않습니다. 그래서 예제는 모두 SQL 로 작성했습니다(18장 `\copy` 만 psql 전용).
- `[심화]` : 처음 공부할 때는 건너뛰어도 되는 내용, `[error]` : 일부러 오류를 보여 주는 예제입니다.
- 금액 단위는 원, 직원 연봉(`salary`)은 만원 단위입니다.
