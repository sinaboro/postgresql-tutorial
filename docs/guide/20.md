# 20장 ∙ 종합 프로젝트 - 쇼핑몰 매출 분석 리포트

## 프로젝트 개요

shop 데이터베이스로 경영진에게 보고할 **매출 분석 리포트**를 만듭니다. 지금까지 배운 JOIN, 집계, CTE, 윈도우 함수, 뷰, 함수를 모두 활용합니다.

예제 파일: `examples/20_project.sql`

## 요구사항

| 번호 | 경영진의 질문 | 사용 기술 |
|---|---|---|
| R1 | 전체 매출, 주문 수, 구매 고객 수, 객단가는? | 집계, 뷰 |
| R2 | 올해 상반기는 작년 같은 달보다 성장했나? | CTE, 셀프 조인 |
| R3 | 우수 고객과 이탈 위험 고객은 누구인가? | RFM, NTILE |
| R4 | 한 번 산 고객이 다시 사는가? 언제까지 남는가? | 재구매율, 코호트 |
| R5 | 어떤 상품이 함께 팔리는가? | 셀프 조인 (장바구니 분석) |
| R6 | 상품별·영업사원별 성과는? | 윈도우 함수 (RANK, 비중) |
| R7 | 기간을 넣으면 분류별 매출을 주는 리포트 | SQL 함수 |

## 조별 과제

아래 중 하나를 골라 쿼리를 작성하고, 결과를 표·차트(19장 pandas 활용 가능)로 정리해 5분간 발표합니다.

1. **등급 개편안**: 현재 grade 와 실제 구매액(15장 `customer_level` 함수)이 맞지 않는 고객을 찾고, 새 등급 기준을 제안하세요.
2. **재고 위험 보고서**: 최근 3개월 판매 속도로 볼 때 30일 안에 재고가 바닥날 상품을 찾으세요.
3. **도시별 마케팅 전략**: 도시별 고객 수, 객단가, 재구매율, 인기 분류를 한 표로 만드세요.
4. **리뷰 분석**: 평점 3점 이하 리뷰가 많은 상품과 그 상품의 매출 추이를 비교하세요.
5. **대시보드 설계**: 위 리포트들을 머티리얼라이즈드 뷰로 만들고 갱신 전략을 설명하세요.
