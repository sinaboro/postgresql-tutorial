## 데이터베이스와 DBMS

**데이터베이스(Database)** 는 여러 사람이 함께 쓰기 위해 체계적으로 모아 둔 데이터의 집합이고, 이를 저장·검색·수정·보호하는 소프트웨어가 **DBMS(Database Management System)** 입니다. PostgreSQL, MySQL, Oracle, SQL Server 가 대표적인 DBMS 입니다.

| 비교 | 엑셀 파일 | 데이터베이스(DBMS) |
|---|---|---|
| 동시 사용 | 한 사람이 열면 다른 사람은 읽기 전용 | 수천 명이 동시에 읽고 써도 일관성 유지 |
| 데이터 규칙 | 아무 값이나 입력 가능 | 자료형·제약 조건으로 잘못된 값 차단 |
| 데이터 양 | 약 100만 행 한계, 느려짐 | 수억 행도 인덱스로 빠르게 검색 |
| 장애 대응 | 파일이 깨지면 끝 | 트랜잭션·로그·백업으로 복구 |
| 권한 | 파일 단위 | 테이블·컬럼·행 단위 권한 |

**관계형 데이터베이스(RDB)** 는 데이터를 행(row)과 열(column)로 된 **테이블**에 저장하고, 테이블끼리는 **키(key)** 로 관계를 맺습니다. 테이블에 질문하는 표준 언어가 **SQL(Structured Query Language)** 입니다.

| SQL 분류 | 의미 | 주요 명령 | 교안 |
|---|---|---|---|
| DDL (Definition) | 구조 정의 | `CREATE`, `ALTER`, `DROP`, `TRUNCATE` | 2장 |
| DML (Manipulation) | 데이터 조작 | `INSERT`, `UPDATE`, `DELETE`, `MERGE` | 3장 |
| DQL (Query) | 데이터 조회 | `SELECT` | 4~10장 |
| DCL (Control) | 권한 제어 | `GRANT`, `REVOKE` | 17장 |
| TCL (Transaction) | 트랜잭션 제어 | `BEGIN`, `COMMIT`, `ROLLBACK` | 14장 |

## 왜 PostgreSQL 인가

- **완전한 오픈소스**(PostgreSQL License): 상용 서비스에도 무료로 쓸 수 있습니다.
- **표준 SQL 준수도가 높고 기능이 풍부**: 윈도우 함수, CTE, JSONB, 배열, 전문 검색, 사용자 정의 타입·함수, 확장(Extension).
- **신뢰성**: MVCC 기반 동시성 제어, 강력한 트랜잭션, 30년 넘게 검증된 엔진.
- **시장**: Stack Overflow 개발자 설문에서 수년째 가장 많이 쓰고 선호하는 데이터베이스로 꼽히며, AWS RDS/Aurora, Google Cloud SQL, Azure, Supabase 등 대부분의 클라우드가 기본 제공합니다.
- **버전 정책**: 매년 가을 메이저 버전 출시, 각 버전 5년 지원. 이 교안은 **PostgreSQL 18** 기준이며 17 이상이면 모든 예제가 동작합니다(13장 skip scan 설명만 18 전용).

> [!TEACH] 도입 10분 운영 팁
> 수강생에게 “여러분이 쓰는 앱 중 데이터베이스를 쓰지 않는 것이 있을까요?”라고 물어 보세요. 카카오톡 메시지, 쇼핑몰 장바구니, 은행 잔액이 모두 DB 행이라는 점을 짚으면 동기 부여가 됩니다.
> 엑셀 비교표에서 **“동시에 고친다면?”** 질문을 던지면 14장 트랜잭션의 복선이 됩니다.

## 설치 (Windows 기준)

1. https://www.postgresql.org/download/windows/ → **Download the installer** (EDB 제공) → 최신 18.x Windows x86-64 를 받습니다.
2. 설치 마법사에서 구성 요소는 기본값(PostgreSQL Server, pgAdmin 4, Stack Builder, Command Line Tools) 그대로 둡니다.
3. **superuser(postgres) 비밀번호**를 입력합니다. 실습실에서는 모두 같은 비밀번호(예: `postgres`)로 통일하면 문제 해결이 쉽습니다.
4. 포트는 기본값 **5432**, Locale 은 기본값(Korean, Korea)을 둡니다.
5. 마지막의 Stack Builder 실행 체크는 해제합니다.
6. 환경 변수 `Path` 에 `C:\Program Files\PostgreSQL\18\bin` 을 추가하면 명령 프롬프트에서 `psql` 을 바로 쓸 수 있습니다.

```
C:\> psql --version
psql (PostgreSQL) 18.6
C:\> psql -U postgres
Password for user postgres:
postgres=#
```

> [!WARN] 설치 단계에서 자주 생기는 문제
> - **비밀번호를 잊어버림**: 재설치보다 `pg_hba.conf` 의 `scram-sha-256` 을 잠시 `trust` 로 바꾸고 서비스를 재시작한 뒤 `ALTER USER postgres PASSWORD '새비번';` 으로 바꾸는 것이 빠릅니다. 끝나면 반드시 원래대로 돌립니다.
> - **5432 포트 사용 중**: 다른 PostgreSQL 이 이미 설치된 경우입니다. 설치 시 5433 을 쓰고 접속 시 `-p 5433` 을 붙입니다.
> - **psql 에서 한글이 깨짐**: 명령 프롬프트에서 `chcp 65001` 을 먼저 실행하거나 psql 안에서 `\encoding UTF8` 을 실행합니다. Windows Terminal 사용을 권장합니다.
> - **macOS**: Postgres.app 또는 `brew install postgresql@18` 이 가장 간단합니다. Linux 는 배포판 패키지(`apt install postgresql`)를 씁니다.

## 접속 도구

| 도구 | 특징 | 추천 상황 |
|---|---|---|
| **psql** | 공식 명령줄 도구, 가장 빠르고 서버 어디에나 있음 | 운영 서버 접속, 스크립트 실행, 면접 대비 |
| **pgAdmin 4** | 설치 시 함께 설치되는 공식 GUI | 입문자, 객체 탐색, ERD 확인 |
| **DBeaver** | 여러 DBMS 를 지원하는 범용 GUI, 자동완성 우수 | 실무 개발, MySQL·Oracle 을 함께 쓰는 경우 |

> [!TIP] 수업 진행 권장
> 강사는 **psql** 과 GUI 를 번갈아 보여 주되, 수강생 실습은 GUI(pgAdmin 또는 DBeaver) 하나로 통일하면 질문이 줄어듭니다. 단, 메타 명령(`\dt` 등)은 psql 에서만 동작한다는 점을 처음에 분명히 말해 둡니다.

## 실습 데이터베이스 만들기

저장소를 내려받은 폴더에서 다음 세 줄을 실행합니다. (pgAdmin 에서는 Query Tool 로 각 파일을 열어 실행해도 됩니다.)

```
git clone https://github.com/sinaboro/postgresql-tutorial.git
cd postgresql-tutorial
psql -U postgres -f setup/00_create_database.sql
psql -U postgres -d shop -f setup/01_schema.sql
psql -U postgres -d shop -f setup/02_seed.sql
```

psql 안에서는 다음처럼 해도 같습니다.

```
postgres=# CREATE DATABASE shop;
postgres=# \c shop
shop=# \i setup/01_schema.sql
shop=# \i setup/02_seed.sql
```

## 자주 쓰는 psql 메타 명령

| 명령 | 의미 | 명령 | 의미 |
|---|---|---|---|
| `\l` | 데이터베이스 목록 | `\c shop` | shop DB 로 접속 전환 |
| `\dt` | 테이블 목록 | `\d 테이블` | 테이블 구조 |
| `\dn` | 스키마 목록 | `\df` | 함수 목록 |
| `\du` | 사용자(롤) 목록 | `\x` | 세로 출력 전환 |
| `\i 파일` | SQL 파일 실행 | `\timing` | 실행 시간 표시 |
| `\?` | 메타 명령 도움말 | `\h SELECT` | SQL 문법 도움말 |
| `\q` | 종료 | `\e` | 편집기로 쿼리 작성 |

> [!QA] 예상 질문
> - **Q. 세미콜론(;)을 꼭 붙여야 하나요?** psql 은 `;` 를 만나야 실행합니다. 붙이지 않으면 프롬프트가 `shop-#` 으로 바뀌며 다음 줄 입력을 기다립니다. GUI 에서는 한 문장만 실행할 때 생략해도 되지만 습관적으로 붙이게 합니다.
> - **Q. 데이터베이스와 스키마는 뭐가 다른가요?** DB 는 독립된 저장소(다른 DB 의 테이블을 바로 조인할 수 없음), 스키마는 DB 안의 폴더입니다. 12장에서 다룹니다.
> - **Q. 대문자로 만든 테이블 이름은?** `CREATE TABLE "Users"` 처럼 큰따옴표로 만들면 그 뒤로도 항상 `"Users"` 로 써야 합니다. 이름은 소문자 + 밑줄(snake_case)로 짓는 것이 PostgreSQL 관례입니다.

## 정리

- DBMS 는 데이터를 안전하게, 동시에, 빠르게 다루기 위한 소프트웨어이며 SQL 로 대화한다.
- psql 메타 명령(`\dt`, `\d`)은 SQL 이 아니라 psql 의 기능이다.
- 실습 DB 는 `setup/` 의 파일 3개로 언제든 초기 상태로 되돌릴 수 있다.
