## 데이터베이스와 DBMS

**데이터베이스(Database)** 는 여러 사람이 함께 쓰기 위해 체계적으로 모아 둔 데이터의 집합이고, 이를 저장·검색·수정·보호하는 소프트웨어가 **DBMS(Database Management System)** 입니다. PostgreSQL, MySQL, Oracle, SQL Server 가 대표적인 DBMS 입니다.

| 비교 | 엑셀 파일 | 데이터베이스(DBMS) |
|---|---|---|
| 동시 사용 | 한 사람이 열면 다른 사람은 읽기 전용 | 수천 명이 동시에 읽고 써도 일관성 유지 |
| 데이터 규칙 | 아무 값이나 입력 가능 | 자료형·제약 조건으로 잘못된 값 차단 |
| 데이터 양 | 약 100만 행 한계, 느려짐 | 수억 행도 인덱스로 빠르게 검색 |
| 장애 대응 | 파일이 깨지면 끝 | 트랜잭션·로그·백업으로 복구 |
| 권한 | 파일 단위 | 테이블·컬럼·행 단위 권한 |

**관계형 데이터베이스(RDB)** 는 데이터를 행(row)과 열(column)로 된 **테이블**에 저장하고, 테이블끼리는 **키(key)** 로 관계를 맺습니다. 테이블에 질문하는 표준 언어가 **SQL(Structured Query Language)** 입니다.

| SQL 분류 | 의미 | 주요 명령 | 교안 |
|---|---|---|---|
| DDL (Definition) | 구조 정의 | `CREATE`, `ALTER`, `DROP`, `TRUNCATE` | 2장 |
| DML (Manipulation) | 데이터 조작 | `INSERT`, `UPDATE`, `DELETE`, `MERGE` | 3장 |
| DQL (Query) | 데이터 조회 | `SELECT` | 4~10장 |
| DCL (Control) | 권한 제어 | `GRANT`, `REVOKE` | 17장 |
| TCL (Transaction) | 트랜잭션 제어 | `BEGIN`, `COMMIT`, `ROLLBACK` | 14장 |

## 왜 PostgreSQL 인가

- **완전한 오픈소스**(PostgreSQL License): 상용 서비스에도 무료로 쓸 수 있습니다.
- **표준 SQL 준수도가 높고 기능이 풍부**: 윈도우 함수, CTE, JSONB, 배열, 전문 검색, 사용자 정의 타입·함수, 확장(Extension).
- **신뢰성**: MVCC 기반 동시성 제어, 강력한 트랜잭션, 30년 넘게 검증된 엔진.
- **시장**: Stack Overflow 개발자 설문에서 수년째 가장 많이 쓰고 선호하는 데이터베이스로 꼽히며, AWS RDS/Aurora, Google Cloud SQL, Azure, Supabase 등 대부분의 클라우드가 기본 제공합니다.
- **버전 정책**: 매년 가을 메이저 버전 출시, 각 버전 5년 지원. 이 교안은 **PostgreSQL 18** 기준이며 17 이상이면 모든 예제가 동작합니다(13장 skip scan 설명만 18 전용).

## 설치 (Windows 기준)

1. https://www.postgresql.org/download/windows/ → **Download the installer** (EDB 제공) → 최신 18.x Windows x86-64 를 받습니다.
2. 설치 마법사에서 구성 요소는 기본값(PostgreSQL Server, pgAdmin 4, Stack Builder, Command Line Tools) 그대로 둡니다. Command Line Tools(psql, pg_dump)는 18장 백업에서 쓰므로 빼지 않습니다.
3. **superuser(postgres) 비밀번호**를 입력합니다. 실습실에서는 모두 같은 비밀번호(예: `postgres`)로 통일하면 문제 해결이 쉽습니다.
4. 포트는 기본값 **5432**, Locale 은 기본값(Korean, Korea)을 둡니다.
5. 마지막의 Stack Builder 실행 체크는 해제합니다.
6. 환경 변수 `Path` 에 `C:\Program Files\PostgreSQL\18\bin` 을 추가하면 명령 프롬프트에서 `psql` 을 바로 쓸 수 있습니다.

```
C:\> psql --version
psql (PostgreSQL) 18.6
C:\> psql -U postgres
Password for user postgres:
postgres=#
```

> [!WARN] 설치 단계에서 자주 생기는 문제
> - **비밀번호를 잊어버림**: 재설치보다 `pg_hba.conf` 의 `scram-sha-256` 을 잠시 `trust` 로 바꾸고 서비스를 재시작한 뒤 `ALTER USER postgres PASSWORD '새비번';` 으로 바꾸는 것이 빠릅니다. 끝나면 반드시 원래대로 돌립니다.
> - **5432 포트 사용 중**: 다른 PostgreSQL 이 이미 설치된 경우입니다. 설치 시 5433 을 쓰고 접속 시 `-p 5433` 을 붙입니다.
> - **psql 에서 한글이 깨짐**: 명령 프롬프트에서 `chcp 65001` 을 먼저 실행하거나 psql 안에서 `\encoding UTF8` 을 실행합니다. Windows Terminal 사용을 권장합니다.
> - **macOS**: Postgres.app 또는 `brew install postgresql@18` 이 가장 간단합니다. Linux 는 배포판 패키지(`apt install postgresql`)를 씁니다.

## 접속 도구 - 수업은 DBeaver 로 진행

| 도구 | 특징 | 이 과정에서 |
|---|---|---|
| **DBeaver** (Community, 무료) | 여러 DBMS 를 지원하는 범용 GUI. 자동완성, 결과 그리드, ER 다이어그램, 데이터 가져오기/내보내기 | **수업 표준 도구**. 모든 실습을 DBeaver 로 진행 |
| **psql** | PostgreSQL 설치 시 함께 설치되는 공식 명령줄 도구 | 서버 확인, 스크립트 일괄 실행, 18장 `\copy`·백업 명령 |
| pgAdmin 4 | 설치 시 함께 설치되는 공식 GUI | 사용하지 않음 (설치는 되어 있으므로 소개만) |

### DBeaver 설치

1. https://dbeaver.io/download/ → **DBeaver Community** 의 Windows (installer) 를 받아 설치합니다. (macOS 는 dmg, Linux 는 deb/rpm)
2. 첫 실행 시 “샘플 데이터베이스를 만들까요?” 질문은 **아니요**, 통계 전송 동의는 원하는 대로 선택합니다.
3. 메뉴가 영어라면 그대로 쓰는 것을 권장합니다(검색·질문할 때 영어 메뉴 이름이 편함). 교안도 영어 메뉴 이름으로 적습니다.

### PostgreSQL 연결 만들기

1. 왼쪽 위 **New Database Connection**(플러그 + 아이콘) 또는 메뉴 `Database → New Database Connection` → **PostgreSQL** 선택 → Next
2. Main 탭 입력

| 항목 | 값 |
|---|---|
| Connect by | Host |
| Host / Port | `localhost` / `5432` |
| Database | `postgres` (처음엔 postgres, shop 을 만든 뒤 하나 더 만들거나 변경) |
| Authentication | Database Native |
| Username / Password | `postgres` / 설치 시 정한 비밀번호, **Save password** 체크 |

3. PostgreSQL 탭에서 **Show all databases** 를 체크하면 왼쪽 트리에 모든 DB 가 보입니다.
4. **Test Connection** → 처음이면 “Download driver files” 창이 뜨고 **Download** 를 누르면 JDBC 드라이버를 받습니다. `Connected` 가 나오면 Finish.

> [!WARN] 강의장 인터넷이 막혀 있다면
> DBeaver 는 첫 연결 때 PostgreSQL JDBC 드라이버를 인터넷에서 내려받습니다. 인터넷이 막힌 강의장이라면 강사 PC 에서 미리 받아 둔 드라이버 폴더(`%APPDATA%\DBeaverData\drivers`)를 복사해 주거나, 드라이버가 포함된 DBeaver 설치 파일을 준비하세요. 개강 전 체크리스트에 넣어 두면 첫날 30분을 아낍니다.

### SQL 편집기 사용법

연결을 선택하고 `Ctrl+]` (또는 메뉴 `SQL Editor → New SQL script`) 로 편집기를 엽니다. 저장소의 예제 파일은 `File → Open File...` 로 열고, 편집기 위쪽의 **활성 연결/데이터베이스 선택 상자**에서 `shop` 을 고릅니다.

| 단축키 | 동작 | 언제 |
|---|---|---|
| `Ctrl+Enter` | 커서가 있는 **문장 하나** 실행 (선택했으면 선택 영역을 한 문장으로 실행) | 쿼리 하나씩 실행 |
| `Alt+X` | **스크립트 실행** - 여러 문장을 차례로 실행, 결과는 탭마다 | 예제 블록 전체, setup 파일 |
| `Ctrl+Space` | 자동완성 (테이블·컬럼 이름) | 항상 |
| `Ctrl+Shift+F` | SQL 정렬(포맷) | 긴 쿼리 정리 |
| `Ctrl+/` | 줄 주석 켜기/끄기 | |
| `Ctrl+Shift+E` | 실행 계획(EXPLAIN) 보기 | 13장 |
| `Ctrl+Shift+O` | 서버 출력(NOTICE) 창 켜기/끄기 | 15장 `RAISE NOTICE` |

> [!TEACH] 예제 파일 실행 요령 (수강생에게 꼭 보여 줄 것)
> - 예제 파일은 `-- @ex 04-01 제목` 주석으로 예제가 나뉩니다. **예제 블록 전체를 마우스로 선택 → `Alt+X`** 가 가장 확실합니다. 선택하지 않고 `Alt+X` 를 누르면 파일 전체가 실행되니 주의시킵니다.
> - DBeaver 는 기본 설정에서 **빈 줄을 문장 구분으로 볼 수 있어**, 빈 줄이 들어간 긴 문장에 `Ctrl+Enter` 를 쓰면 일부만 실행됩니다. 문장 사이를 `;` 로 확실히 끝내고, 헷갈리면 선택 후 실행하게 하세요. (설정: `Window → Preferences → Editors → SQL Editor → SQL Processing → Blank line is statement delimiter`)
> - 결과는 아래 **결과 그리드**에 표로 나옵니다. INSERT/UPDATE 결과(`UPDATE 1`)는 **Statistics** 탭의 Updated Rows 로 확인합니다. 교안의 ‘실행 결과’는 psql 형식이라 모양만 다를 뿐 내용은 같습니다. 숫자·날짜 표시 형식은 DBeaver 설정에 따라 조금 다를 수 있습니다.
> - 오류가 나면 아래쪽에 빨간 메시지가 뜹니다. 트랜잭션 모드(14장)에서 오류가 났다면 Rollback 을 눌러야 다음 실행이 됩니다.

### psql 메타 명령과 DBeaver 대응표

`\` 로 시작하는 psql 메타 명령은 SQL 이 아니어서 **DBeaver 에서는 실행되지 않습니다**. 그래서 이 저장소의 예제는 메타 명령 대신 같은 정보를 SQL(`information_schema`)로 조회하도록 작성했습니다(예: 01-03, 01-04). 18장의 `\copy` 만 psql 전용입니다.

| psql | 의미 | DBeaver 에서는 |
|---|---|---|
| `\l` / `\c shop` | DB 목록 / DB 전환 | 왼쪽 Database Navigator, 편집기 위 데이터베이스 선택 상자 |
| `\dt` / `\dv` | 테이블 / 뷰 목록 | Navigator 의 `shop → Schemas → public → Tables / Views` |
| `\d 테이블` | 테이블 구조 | 테이블 더블클릭 → **Properties**(Columns, Constraints, Indexes) / **DDL** 탭 |
| `\df` | 함수 목록 | Navigator 의 `Functions` (Procedures 포함) |
| `\du` | 롤 목록 | Navigator 의 연결 아래 `Roles` |
| `\i 파일` | 파일 실행 | 파일 열기 → `Alt+X` |
| `\timing` | 실행 시간 | 결과 그리드 아래 상태 표시줄에 자동 표시 |
| `\x` | 세로 출력 | 결과 그리드에서 `Tab` 키 (Record 보기 전환) |
| `\copy` | CSV 입출력 | 테이블 우클릭 → Export Data / Import Data (18장) |

## 실습 데이터베이스 만들기 (DBeaver)

1. 저장소를 내려받습니다. git 이 있으면 `git clone https://github.com/sinaboro/postgresql-tutorial.git`, 없으면 GitHub 의 **Code → Download ZIP** 후 압축을 풉니다.
2. **postgres** 데이터베이스에 연결된 상태에서 `setup/00_create_database.sql` 을 열고 `Alt+X` → `shop` DB 가 생깁니다. (shop 에 연결된 편집기가 열려 있으면 DROP 이 실패하므로 먼저 닫습니다.)
3. 왼쪽 Navigator 에서 연결을 우클릭 → Refresh 후 `shop` 이 보이면, 편집기의 데이터베이스 선택 상자를 **shop** 으로 바꿉니다. (또는 Database 를 `shop` 으로 한 연결을 하나 더 만듭니다.)
4. `setup/01_schema.sql` → `Alt+X`, 이어서 `setup/02_seed.sql` → `Alt+X`.
5. 새 편집기에서 `SELECT count(*) FROM orders;` 가 **120** 이면 준비 완료입니다.

> [!TIP] 실습 데이터 초기화
> 3장처럼 데이터를 바꾸는 실습 뒤에는 4번(01_schema → 02_seed)만 다시 실행하면 처음 상태로 돌아갑니다. 명령 프롬프트에 익숙한 수강생은 psql 로도 할 수 있습니다: `psql -U postgres -d shop -f setup/01_schema.sql` , `psql -U postgres -d shop -f setup/02_seed.sql`

> [!QA] 예상 질문
> - **Q. 세미콜론(;)을 꼭 붙여야 하나요?** psql 은 `;` 를 만나야 실행합니다. 붙이지 않으면 프롬프트가 `shop-#` 으로 바뀌며 다음 줄 입력을 기다립니다. GUI 에서는 한 문장만 실행할 때 생략해도 되지만 습관적으로 붙이게 합니다.

## 정리

- DBMS 는 데이터를 안전하게, 동시에, 빠르게 다루기 위한 소프트웨어이며 SQL 로 대화한다.
- 실습은 DBeaver 로: 블록 선택 후 `Alt+X`, 한 문장은 `Ctrl+Enter`.
- psql 메타 명령(`\dt`, `\d`)은 SQL 이 아니라 psql 의 기능이라 DBeaver 에서는 동작하지 않는다.
- 실습 DB 는 `setup/` 의 파일 3개로 언제든 초기 상태로 되돌릴 수 있다.
